**1\. Pre-application OSS proof of concept**  
**Purpose.** Demonstrate that the central research hypothesis is real, measurable and technically feasible before asking ARIA to fund the broader generalisation and research programme.

**What it is.** A compact open-source research library built on top of the Etiq execution graph, using one synthetic multi-agent finance/payment workflow.

• **Semantic specification compiler:** Compile human intent, an existing ontology, and business/security constraints into stable, source-grounded specification elements.

• **State-semantic mapper & verifier:** Associate those elements with Etiq execution states and test whether each state is consistent with the relevant intent, ontology concepts and rules.

• **Endpoint vs intermediate-state experiment:** Compare checks on only the initial/final states with the same checks across relevant intermediate execution states.

• **Context-ablation experiment:** Compare state-only, selected/causal context and full-history context for semantic labelling quality.

• **Small semantic-evolution slice:** Include a small number of cases where interpretation changes or new evidence exposes an ontology/rule gap.

• **Failure injection:** Inject representative payment failures such as amount mutation, bank-account substitution, stale approval, wrong PO association and dropped/reintroduced constraints.

• **Training-data export:** Package labelled workflow segments and failures into a structured format that can later be reused for agent training/evaluation.

LOWEST PRIORITY• **Formalisation demonstrator:** Include one small machine-checkable rule, such as payment amount equalling the authorised amount.

**PoC outputs.** Public repository, reproducible benchmark harness, preliminary endpoint-vs-intermediate results, context-ablation results, labelled workflow examples, and a short arXiv/workshop preprint.

**IP boundary.** Etiq execution-graph construction remains pre-existing background IP. The semantic mapping, propagation, benchmarking and evaluation layer implemented on top is open source.

THIS IS JUST THE EVIDENCE FOR A LARGER APPLICATION SO IT IS A SMALL REPO.
